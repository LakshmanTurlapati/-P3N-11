<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → job-status API | The client sees job state and playback URLs but cannot decide the underlying generation state. |
| API → sqlite/object store | Generation metadata and audio artifacts cross into local persistence and must stay path-safe. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-03-01 | Information Disclosure | `LocalObjectStore` / playback route | medium | mitigate | Serve audio only through controlled URLs or `FileResponse`; do not expose raw filesystem paths or inline bytes. |
| T-02-03-02 | Tampering / DoS | job store and retry flow | medium | mitigate | Keep job rows immutable once written, create a new job for every retry, and return status through a bounded polling path. |
| T-02-03-SC | Tampering | local sqlite and object-store writes | high | mitigate | Constrain all persistence to the local storage root and block any code path that tries to bypass the object-store abstraction. |
</threat_model>
