<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> playback/status API | The client sees job state and clip URLs but cannot decide the underlying generation state. |
| Browser -> controlled audio URL | The client consumes playback URLs and must not learn raw object-store or filesystem paths. |
| Retry UI -> job resubmission | Cached text, voice, and tone inputs are untrusted until the browser resubmits them. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-06-01 | Information Disclosure | playback URL / audio element | medium | mitigate | Keep playback constrained to the relative `/generations/{job_id}/audio` route and never surface raw paths or object-store details in the browser. |
| T-02-06-02 | Tampering | retry state in `StudioShell` | medium | mitigate | Keep the last request inputs in component state only and resubmit them through the existing generation contract. |
| T-02-06-SC | Tampering | browser session state | low | accept | Session-scoped attempt history is expected in Phase 2 and is not persisted across refresh. |
</threat_model>
