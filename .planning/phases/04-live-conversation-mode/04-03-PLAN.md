<objective>
**As a** studio user, **I want to** interrupt a speaking response and see each turn’s latency, **so that** I can recover from overlap and judge how responsive the live conversation feels.

Purpose: Close the live conversation loop with cooperative cancellation and measurable turn latency.
Output: Interrupt handling, timing metadata, a compact latency chip, and regression coverage for cancel/resume behavior.
Scope note: Keep interruption cooperative and best-effort; do not add a debug timeline surface or a separate diagnostics route.
</objective>
