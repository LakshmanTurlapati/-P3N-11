| Boundary | Description |

| Browser mic stream -> VAD barge-in monitor | Untrusted audio energy crosses into interruption logic and must only affect the active live turn. |
| Browser playback -> existing interrupt route | The browser can stop audio immediately, but the server must still own the authoritative turn cancel state. |
| Failed turn record -> next session turn | Failure state must remain scoped to the failed turn and cannot leak into the next turn in the same session. |
