<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Persona prompt -> deterministic responder | The response prompt must carry the original-voice boundary and prohibited associations before any text is emitted. |
| Response text -> controlled audio URL | The browser should receive only the reply text and same-origin playback URL, not model internals or raw storage paths. |
| Session memory -> turn record | Recent-turn context must come from authoritative server records and must not persist across refresh. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-02-01 | Spoofing / Tampering | `services/speech-worker/providers/conversation_provider.py` | high | mitigate | Enforce the original-voice boundary and prohibited associations in the schema and regression tests so the responder cannot impersonate a protected identity. |
| T-04-02-02 | Information disclosure | `services/api/app/services/conversation_runtime.py` | medium | mitigate | Keep the response prompt and short session memory server-side; expose only the final reply text and controlled playback URL to the browser. |
| T-04-02-03 | Tampering | `services/api/app/routes/conversation.py` | medium | mitigate | Serve response audio only through the controlled conversation route and validate turn/session ids before returning playback metadata. |
</threat_model>
