## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/UI -> API rights gate | Client-selected voice state can be wrong or forged, so the server must decide approval. |
| API -> bundled voice registry | Server-owned voice metadata must remain canonical and not drift into protected-identity wording. |
| Route -> future generation path | Rights enforcement must hold before any generation route is allowed to consume the profile. |
