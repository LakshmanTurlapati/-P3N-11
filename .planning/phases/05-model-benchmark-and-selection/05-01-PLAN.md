<objective>
Create the reproducible benchmark foundation for Phase 05.

Purpose: Make VAD, TTS, and end-to-end candidate comparisons repeatable by fixing corpus inputs, result schemas, timing fields, gate fields, and report outputs before any candidate-specific work starts.
Output: `services/speech-worker/benchmarks/` package with corpus manifest loading, Pydantic schemas, deterministic fixtures, report writer scaffolding, and fixture-only pytest coverage.
Scope note: This plan does not run real model benchmarks or choose providers. It creates the shared contract that later plans must use for evidence and reporting.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repo manifest -> benchmark loader | Manifest strings and fixture paths are data and must be validated before use. |
| WAV fixtures -> benchmark rows | Audio files can be malformed, missing, or oversized; loader failures must be explicit. |
| Provider/model text -> Markdown report | Candidate names, blockers, and generated text are untrusted report data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01-01 | Tampering | `services/speech-worker/benchmarks/corpus.py` | medium | mitigate | Normalize fixture paths and reject any path outside `services/speech-worker/benchmarks/corpus/fixtures`. |
| T-05-01-02 | Denial of service | `services/speech-worker/benchmarks/corpus/fixtures/*.wav` | medium | mitigate | Keep checked-in WAV fixtures tiny and validate duration/sample metadata before scoring. |
| T-05-01-03 | Tampering / Spoofing | `services/speech-worker/benchmarks/reporting.py` | medium | mitigate | Escape provider/model text before inserting into Markdown and serialize raw values into JSON/CSV as data. |
| T-05-01-04 | Abuse / Safety | `services/speech-worker/benchmarks/corpus/manifest.json` | high | mitigate | Exclude protected-character and real-performer imitation targets from manifest strings and require safety notes for tone/persona cases. |
</threat_model>
