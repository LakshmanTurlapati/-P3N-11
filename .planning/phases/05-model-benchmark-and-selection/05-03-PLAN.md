<objective>
Close Phase 05 by recording end-to-end speech-to-speech feasibility findings and producing the provider recommendation report.

Purpose: Give the team an evidence-based provider selection outcome without over-expanding the phase into broad end-to-end model integration or risky default migration.
Output: S2S findings module, final recommendation builder, Markdown/JSON/CSV report artifacts, and tests proving blocked candidates and conservative default decisions.
Scope note: This plan may run at most one end-to-end model only if setup is already approved and cheap. Otherwise it records precise blocker evidence. It must not change application defaults unless the report proves the winner is runnable, license-safe, and low-risk.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Research notes -> S2S findings | Research notes are not benchmark evidence and must become blocker/evidence rows before recommendation. |
| Candidate benchmark rows -> default decision | The report may recommend, but app defaults change only after hard gates pass. |
| External GPU runs -> repo report | External run outputs must be summarized as evidence references, not trusted blindly as local test results. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-03-01 | Spoofing | `services/speech-worker/benchmarks/s2s_findings.py` | medium | mitigate | Require explicit `attempted_setup_evidence`, `blocker_reason`, or `external_evidence_ref` for each S2S finding. |
| T-05-03-02 | Tampering | `services/speech-worker/benchmarks/recommendation.py` | high | mitigate | Keep license, safety, and integration gates as hard blockers before a candidate can be recommended or used for defaults. |
| T-05-03-03 | Denial of service | optional S2S runtime execution | medium | mitigate | Do not run broad heavy S2S models in normal local tests; treat GPU execution as manual/external and findings-first. |
| T-05-03-04 | Abuse / Safety | default provider switch | high | mitigate | Preserve consent-safe original-voice boundary and keep defaults conservative unless evidence proves the winner is safe and low-risk. |
</threat_model>
