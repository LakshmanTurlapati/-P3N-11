<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Audio-turn record -> transcript review UI | Transcript text must be treated as untrusted text, not as HTML or implicit composer state. |
| STT provider -> browser | The browser can display the transcript, but it must not run the primary speech-recognition path itself. |
| Package install -> worker runtime | Installing or relying on the SUS package path must be gated by human approval and fallback validation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-31 | Tampering / XSS | `apps/web/components/studio-shell.tsx` | high | mitigate | Render transcripts as text in editable controls and require explicit `Use as generation text` before copying into the composer. |
| T-03-32 | Spoofing / Tampering | `services/speech-worker/providers/faster_whisper_stt_provider.py` | medium | mitigate | Keep transcription behind `STTProvider` so the browser cannot bypass the worker boundary with SpeechRecognition. |
| T-03-33 | Information disclosure | `services/api/app/services/audio_turn_jobs.py` | medium | mitigate | Keep transcript metadata session-scoped and avoid durable history or raw artifact exposure. |
| T-03-3-SC | Supply chain / Tampering | package install path | high | mitigate | Human checkpoint before relying on the SUS package, plus deterministic fallback behavior in tests and local validation. |
</threat_model>
