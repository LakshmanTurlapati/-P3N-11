<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Audio-turn API -> VAD worker | The API hands untrusted capture blobs to the worker; only the provider boundary may interpret them. |
| Worker -> audio-turn record | Segment metadata must not be fabricated in the browser; it must come from the provider-backed runtime. |
| Package install -> worker runtime | Installing or relying on the SUS package path must be gated by human approval and validated fallback behavior. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-21 | DoS | `services/api/app/routes/audio_turns.py` | high | mitigate | Keep normalization and segmentation off the request thread, and reject malformed or oversized audio before the runtime starts. |
| T-03-22 | Information disclosure | `services/api/app/services/audio_turn_jobs.py` | medium | mitigate | Keep object-store paths server-side and expose only the compact metadata and controlled artifact route. |
| T-03-23 | Tampering | `services/speech-worker/providers/silero_vad_provider.py` | medium | mitigate | Lock the provider behind `VADProvider` and keep deterministic fixtures so the browser cannot spoof segment boundaries. |
| T-03-2-SC | Supply chain / Tampering | package install path | high | mitigate | Human checkpoint before relying on the SUS package, plus explicit fallback behavior when the worker runtime is missing FFmpeg or the approved provider path. |
</threat_model>
